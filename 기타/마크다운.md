### 1. 글자 크기 조절 (헤드라인)

마크다운에서 글자를 크게 만드는 것은 **제목(Heading)** 기능을 사용합니다. `#`의 개수가 적을수록 글자가 커집니다.

- `# 가장 큰 제목 (H1)`
- `## 두 번째로 큰 제목 (H2)`
- `### 세 번째로 큰 제목 (H3)`
- `#### 작은 제목 (H4)`

> **Tip:** `#` 뒤에는 반드시 **한 칸 띄어쓰기**를 해야 적용됩니다!

---

### 2. 글자 강조 (Bold, Italic)

텍스트의 특정 부분을 강조하고 싶을 때 사용합니다.

- **굵게:** `**텍스트**` 또는 `__텍스트__`    
- _기울임:_ `*텍스트*` 또는 `_텍스트_`
- ~~취소선~~: `~~텍스트~~`
- ==형광펜(옵시디언 전용)==: `==텍스트==`

---

### 3. 목록 만들기 (List)

개발 일지를 작성할 때 가장 많이 쓰게 될 기능입니다.

- **순서 없는 목록:** `-` 또는 `*` 또는 `+` (내용 입력)    
- **순서 있는 목록:** `1.`, `2.` (숫자 입력)
- **체크리스트:** `- [ ] 할 일`, `- [x] 완료된 일`

---

### 4. 개발자 필수: 코드 블록 (Code Block)

코드를 작성할 때 배경색을 넣어 가독성을 높여줍니다.

- **한 줄 코드:** `코드` (키보드 1번 왼쪽의 백틱 기호)    
- **여러 줄 코드 블록:** 백틱 3개를 위아래로 감쌉니다.

    ```java
    public class Hello {
        public static void main(String[] args) {
            System.out.println("Hello World");
        }
    }
    ```

> **Tip:** 첫 번째 ``` 뒤에 `java`, `javascript`, `html` 등 언어 이름을 적으면 문법 강조(Syntax Highlighting)가 적용됩니다.

---

### 5. 옵시디언 화면 자체를 확대하고 싶다면?

글자 크기 서식이 아니라, **옵시디언 프로그램 화면 전체**가 작아서 키우고 싶으신 거라면 아래 단축키를 사용하세요.

- **화면 확대:** `Cmd/Ctrl` + `+`
- **화면 축소:** `Cmd/Ctrl` + `-`
