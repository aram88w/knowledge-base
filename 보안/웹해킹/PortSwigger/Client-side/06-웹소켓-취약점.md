## 웹소켓 취약점

### 웹소켓

클라이언트와 서버 간에 **실시간 양방향 통신**을 가능하게 하는 HTML5 표준 통신 프로토콜
처음 연결은 HTTP 핸드셰이크를 통해 이루어지고 연결을 끊을 때까지 유지됨. 웹소켓 연결이 설정되면 클라이언트와 서버는 비동기 방식으로 메시지를 주고 받을 수 있음. 보통 JSON 형식 사용
예: 실시간 채팅 및 메신저, 주식 및 실시간 금융 거래 정보, 실시간 알림 및 대시보드 업데이트 

웹소켓은 일반적으로 클라이언트 측 JavaScript를 사용하여 연결함.
``` js
var ws = new WebSocket("wss://normal-website.com/chat");
```

그러면 브라우저와 서버는 HTTP를 통해 웹소켓 핸드셰이크를 수행
``` http
GET /chat HTTP/1.1
Host: normal-website.com
Sec-WebSocket-Version: 13
Sec-WebSocket-Key: wDqumtseNBJdhkihL6PW7w==
Connection: keep-alive, Upgrade
Cookie: session=KOsEJNuflw4Rd9BDNrVmvwBF9rEijeE2
Upgrade: websocket
```

``` http
HTTP/1.1 101 Switching Protocols
Connection: Upgrade
Upgrade: websocket
Sec-WebSocket-Accept: 0FFP+2nmNIf/h+4BP36k9uzrYGk=
```

브라우저에서 클라이언트 측 JavaScript를 사용하여 메시지 전송 
``` js
ws.send("Peter Wiener");
```
