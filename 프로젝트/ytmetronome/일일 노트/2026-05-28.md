JavaScript 클로저 때문입니다. 간단한 예시로 설명하면:

``` ts
// 첫 번째 렌더링: playbackRate = 1.0
useEffect(() => {
  const handleKeyDown = (e) => {
    // 이 함수가 만들어지는 순간 playbackRate = 1.0이 "찍힘"
    handlePlaybackRateChange(playbackRate - 0.05); // 영원히 1.0 - 0.05
  };
  window.addEventListener("keydown", handleKeyDown);
}, []); // ← 빈 배열이면 딱 한 번만 등록
```

`handleKeyDown` 함수는 **만들어질 때의 `playbackRate` 값을 기억**합니다. 나중에 `setPlaybackRate(0.95)`로 상태가 바뀌어도, 이미 등록된 `handleKeyDown`은 여전히 **처음 값 1.0**을 보고 있습니다. React 상태는 "실시간 참조"가 아니라 **렌더링 시점의 스냅샷**이거든요.

의존성에 `playbackRate`를 넣으면:

1. 배속이 바뀔 때마다 **이전 리스너 제거** (cleanup)
2. **새 값을 캡처한 리스너 재등록**

그래서 매번 최신 값을 사용할 수 있는 겁니다.
